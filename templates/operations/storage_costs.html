How this is estimated

From the app's own records: file sizes, how long each file has been stored, and authorised downloads (each counted as a full download). Rates: storage ${{ rates.storage }} per GB-month, data out ${{ rates.egress }} per GB, uploads ${{ rates.put }} and downloads ${{ rates.get }} per 1,000 requests. AWS bills the whole account, not each folder, and the first 100 GB of data out each month is free, so your real bill can be lower. Check AWS Billing for the exact figure. Deleting a project hides it everywhere, keeps its payment and audit history, and permanently removes every stored version of its files.
